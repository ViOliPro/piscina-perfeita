## 3. Descrição do serviço

O Piscina Perfeita é um sistema de gestão voltado a condomínios com piscina, oferecendo:

- Controle de estoque de produtos químicos e de limpeza, com sugestão de reposição.
- Registro de análises de qualidade da água (pH, cloro, alcalinidade, temperatura).
- Registro de aplicação de produtos e histórico completo de movimentações.
- Controle de acesso por perfil (Administrador, Operador, Visualizador), com isolamento total de dados entre condomínios distintos.

O serviço é destinado a síndicos moradores e síndicos profissionais. (Perfis para empresas de manutenção de piscina estão previstos para versões futuras e não fazem parte do escopo atual.)

## 6. Isolamento de dados entre condomínios

O sistema foi construído para que cada condomínio (Local) tenha acesso exclusivamente aos próprios dados. Um Administrador ou Operador vinculado a um condomínio não tem acesso a dados de outro condomínio dentro do sistema, salvo os casos de acesso administrativo geral previstos internamente para operação e suporte técnico do serviço.
